# Weather App + Movie Search App

## Project Overview

This project contains two interactive web applications:

1. Weather App
2. Movie Search App

The applications use public APIs to fetch and display dynamic information.

## Features

### Weather App

- Search weather by city
- Display temperature
- Display humidity
- Display wind speed
- Display weather information
- Handle invalid city searches

### Movie Search App

- Search movies
- Display movie posters
- Display movie titles
- Display movie type
- Display release year
- Handle invalid movie searches
